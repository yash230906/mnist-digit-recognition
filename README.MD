# MNIST Handwritten Digit Recognition

## Project Overview
This project uses a neural network and the MNIST dataset to recognize handwritten digits from 0 to 9.

## Technologies Used
- Python
- Jupyter Notebook
- Google Colab
- TensorFlow / Keras (if used in the notebook)
- MNIST Dataset

## Project Files
- `mnist_digit_recognition.ipynb` — Project code and execution results.
- `MNIST_Project_Report.docx.pdf` — Project report.
- `MNIST_Project_Presentation (1).pptx` — Project presentation.

## How to Run
1. Open the notebook in Google Colab.
2. Run the notebook cells in order.
3. Review the model's accuracy and predictions.

## Results
The notebook trains and evaluates a model for handwritten digit recognition. See the notebook for the actual results.
